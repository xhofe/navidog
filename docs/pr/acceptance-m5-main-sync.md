整合分支 `codex/m5-main-sync`：以 PR #33 的 `4730e2c` 为起点，合入 `upstream/main @ 874baa8`。这次同步只处理整合问题；[PR #33 审查](review-pr-33.md)第 9 节的 M5 整改清单仍独立跟踪。

- 保留 #32 的 113 个内置命令和多语言元数据。插件命令在同一目录登记，保留既有位置、快捷键及按插件卸载的行为。命令面板仍留待下一阶段。
- 保留 #36 的分区解析和依赖版本，及 #37 的序列归属迁移、加锁与冲突检查。原生序列归属加入 M5 的共享快照；插件快照保留修订号、未知项与附件，仍走既有冻结预览和执行路径。
- 将 M5 的兼容补丁移到修复后的 `russh 0.65.1`；仅调整 RSA/PKCS#1 版本及借用类型。未新增审计忽略项，且已对照已发布版本确认 vendored SSH agent 源码一致。SQLite 依赖保留 `rusqlite 0.41.1` / `libsqlite3-sys 0.39.1`。

## 本机验证（2026-11-14）

- 格式、全工作区 Clippy（所有目标，`-D warnings`）、裸值、i18n、方言分支和依赖方向检查通过。`cargo deny --all-features check` 与 `cargo audit` 通过；审计仍报告维护状态等警告。
- DB、Schema、Query 实库命令共通过 103 项，含 MySQL 分区注释、MySQL/PostgreSQL SSH 隧道、PostgreSQL 重建后 `serial` 续接及其他表的序列归属不变。MySQL 8、MariaDB 11、PostgreSQL 16 的查询计划解析通过。
- PostgreSQL 插件通过结构化快照、DDL 预览与保存及多结果测试；MySQL 插件通过非事务 DDL 部分失败后重新加载且不重复执行的测试。真实插件运行时通过 PostgreSQL 长查询取消，约 492 ms。验证使用独立的 Compose 项目，测完已停止并移除本次容器。
- macOS Metal 截图测试生成 76 张；已查看主窗口及插件空页、详情、授权、运行限额的浅深色。插件详情的一条英文授权提示仍由 #33 的本地化整改覆盖。
- `cargo test --workspace --locked` 通过 415 项（76 套件，含空套件）。包括 113 个内置命令的本地化、快捷键和 Action 验证，以及插件命令随停用、权限变更移除且不影响内置命令的回归。
- release 性能抽测：导航树 p95 1.27/1.51 ms；SQL 编辑器 5 万行首次解析 341 ms，各场景 p95 不超过 2.04 ms。结束并发验证后复测 10 万行 × 20 列网格：逐行/跳跃 p95 为 4.02/4.84 ms，20 列启用插件格式化后为 4.55/5.71 ms，两次均 0/600 帧超过 8.3 ms。
- 此记录覆盖本机验证；独立整合分支尚未推送，未触发远程 CI。
